Why Synkban?

Simple files underneath. Serious speed on top.

Built for personal workflows that should still work ten years from now — fast on your keyboard, gentle on your sync folder, and safe against accidents.

{}

Plain files, zero lock-in

No database, no proprietary vault, and no sign-up wall. Every board, list, and card is a clean JSON file you can inspect, back up, or copy anywhere.

⇄

Conflict-friendly sync

One file per card plus sidecar attachments mean edits on different cards never clash in Syncthing, Dropbox, iCloud, or Git. External edits refresh every 15 seconds.

◫

Kanban & Notes on one board

Track visual pipelines in Kanban Mode, or press V to read and write long-form specs side by side in Notes Mode without modal fatigue.

✓

Crash-safe & built to last

Deliberate Cmd/Ctrl+S saves keep sync clean while local crash drafts protect open typing. Two-step archive, 100-version history, and offline PDF/A-2u exports guard your work.

Everything you need, nothing bloated

Designed to stay out of your way

Every interaction works cleanly with the keyboard, mouse, or long-press touch — from quick task capture to archival PDF reports.

See every board at a glance

Start on Your Boards with custom colours, total card counts, highlighted overdue counts, and relative last-edited times. Drag or arrow-move boards into any order.

  • Switch boards in one keystroke (, / . or J / K) or via the bottom Board Dock.
  • Per-session memory remembers your focused card, scroll position, and active filter when switching between boards.
  • Custom board colours adapt automatically in both Light and Dark mode.

Capture cards in one line with Quick-add

Press N in any list and add labels or due dates right inside the card title — Synkban parses them live and previews what will be applied before you hit Enter.

  • #label matches existing labels loosely (ignoring case, spaces, and dashes) or creates new ones on the spot.
  • Numbers like #42 stay literal title text so issue numbers are never swallowed.
  • due:fri, due:tomorrow, due:+3d, or due:2026-12-01 set the due date in one step.

Due dates that speak human, picked at keyboard speed

Dates within a week read relatively (Today, Tomorrow, in 3d, Overdue 2d); further out they show the calendar date so you never have to do mental date math.

  • Press Cmd/Ctrl+U inside a card and type tomorrow, fri, +2w, or 2026-12-01.
  • Or press ↓ to step through the calendar grid by day, week, month, or year.

Structured descriptions with Tables, Matrices & Inline Images

Write headings, code blocks, quotes, nested lists, smart links, tables, and transposable 2D Matrices. Everything stays structured and clean — never raw HTML.

  • Matrices give you an open top-left corner, centred row and column headers, per-cell alignment, and one-step Transpose.
  • Paste screenshots directly into a description, or pick any attached image with Cmd/Ctrl+K then M.
  • Flat Checklists (Cmd/Ctrl+L) and file Attachments up to 50 MB keep everything for a task in one card.
Matrix inside Notes Mode — also supports one-step Transpose (Cmd/Ctrl+K → X).

Filter by text, due date & labels

Press F to narrow cards using combined AND filters across titles, descriptions, checklists, Overdue / This week / Until…, and board labels — with matching/total counts.

100-version Card History & diffs

Press Cmd/Ctrl+J on any card to browse its last 100 content snapshots with field-by-field additions and removals — even row-by-row table diffs.

Offline archival PDF/A-2u export

Press Cmd/Ctrl+P to export a saved card as a self-contained PDF/A-2u document with embedded fonts, clickable links, inline diagrams, repeating table headers, and checklists.

Attachments & inline images

Drop files anywhere onto an open card or paste images from the clipboard. Image tiles show thumbnails and an in text badge when embedded in the description; other files show extension badges.

Ordered labels & safe Label Merge

Press G to open the Label Drawer. Drag or press Shift+↑/↓ to reorder labels everywhere on the board, or merge duplicates safely when renaming.

Two-step Archive safety

Boards, cards, and even deleted lists' cards go to the Archive Panel (A) first as Orphaned Cards or archived items — restore with one click or confirm permanent deletion.

Contextual shortcut help (?)

No cheat sheets to memorise: press ? anywhere outside a text field and the help dialog opens straight to the tab for where your focus is (Boards, Board, Notes, Card, or Editor).

Themes, startup view & data folder

Open Settings from any view to pick System, Light, or Dark appearance, launch straight into your last board, or point the Desktop App at a synced folder.

Make it yours

Four ways people actually use Synkban

Start simple with one board, then adapt Synkban's views and plain-file storage to match how you think and work.

Daily Tasks

Personal Project Hub

Use Kanban Mode with Backlog, Doing, and collapsed Done (C). Capture tasks fast with #label due:fri, filter by This week on Monday morning, and keep the Board Overview as your triage dashboard.

Long-Form Writing

Living Reference Notebook

Create a board for docs, study notes, or meeting logs and switch it to Notes Mode (V). Each board remembers its own mode, so notebooks open directly as List Tabs + inline Notes Pane on every device.

Multi-Device Sync

Private Sync Without the Cloud Tax

Point Settings → Data folder on each computer to a shared Syncthing, Dropbox, or iCloud Drive folder. Edit offline on a plane, let your sync tool merge files later, and see external updates flow in automatically.

Deliverables & Records

Clean PDF/A Handoffs

Draft specs with embedded screenshots, checklists, and comparison matrices, then press Cmd/Ctrl+P to share a crisp archival PDF/A-2u snapshot with clients or teammates who don't use Synkban.

Get started in minutes

Install the Desktop App

Free, open-source installers for macOS, Windows, and Linux — everything runs locally out of the box.

macOS (Apple Silicon)

Download the .dmg installer (or .zip archive) from the latest GitHub Release and drag Synkban.app into Applications.

Download from GitHub Releases

First launch on macOS: Release builds are currently unsigned, so macOS Gatekeeper may say "Synkban.app is damaged and can't be opened." Run this once in Terminal, then open Synkban normally: 
sudo xattr -cr /Applications/Synkban.app

Windows

Download and run the .exe NSIS installer from the latest GitHub Release. Synkban installs a native desktop window with zero background services or external dependencies.

Download Windows Installer

Linux

Choose either the portable .AppImage (make executable and run) or the .deb package for Debian/Ubuntu from the latest GitHub Release.

For Self-Hosters & Power Users

Technical Reference, Docker & CLI

Using the Desktop App? You don't need anything in this section — head straight to the User Guide. If you want a self-hosted web server, mobile PWA, or raw folder layout, everything technical lives separately below.

Standalone Web Server

Single self-contained binary with embedded web assets. Configure via --data-dir, DATA_DIR, HOST, and PORT. Place behind a private network or login proxy.

HOST=0.0.0.0 PORT=8080 ./synkban

Docker & Mobile PWA

Multi-arch container (ghcr.io/waschmittel/synkban) ready for Tailscale or Traefik + Tinyauth — installable as a PWA on iOS, Android, and desktop with long-press touch drag.

docker pull ghcr.io/waschmittel/synkban:latest

JSON Layout & synkban.toml

Clean separation between synced boards/ data and machine-local ~/.config/synkban/ settings + crash drafts, using atomic renames and sidecar attachments.

data_dir = "~/Sync/synkban"
startup_view = "last"
