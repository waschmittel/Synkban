Synkban User Guide

Synkban is a local-first, keyboard-driven kanban board and structured note-taking workspace whose data lives as plain JSON files and standalone attachment files on your disk. There is no database, no cloud account, and no vendor lock-in — you own your boards completely and can sync them with whatever tool you already trust.

Shortcut notation: Throughout this guide, Cmd/Ctrl means Cmd (⌘) on macOS and Ctrl on Windows and Linux. Press ? anywhere outside a text field to open the contextual in-app shortcut reference.

Why Synkban?

Most kanban and note-taking apps store your work inside an opaque cloud database or a single monolithic database file. That makes true file-based syncing fragile, backups awkward, and long-term ownership uncertain. Synkban flips that model: every board, list, card, and attachment is a clean file in a folder you control, paired with a fast interface designed for keyboard, mouse, and touch alike.

Core Advantages

  • Plain files, zero lock-in: No database server, no sign-up, and no proprietary format. Back up by copying a folder or inspect any file in a plain text editor.
  • Conflict-friendly file sync: Each card is its own JSON file and attachments store metadata sidecars separately, so editing different cards across Syncthing, Dropbox, iCloud Drive, Nextcloud, Git, or rsync stays conflict-free.
  • Live external change awareness: Synkban checks your Data Directory every 15 seconds and refreshes external sync changes automatically without interrupting active typing or dropping keyboard focus.
  • Kanban Mode & Notes Mode on the same cards: Track pipelines side by side or press V to turn any board into List Tabs plus a full inline Notes Pane.
  • Keyboard-first across macOS, Linux, and Windows: Navigate, reorder, quick-add with #label and due:, pick dates, build tables/matrices, browse history, and export PDFs without touching the mouse.
  • Deliberate saves with crash safety: Card edits save atomically on Cmd/Ctrl+S, keeping sync clean and history meaningful, while machine-local crash drafts safeguard unsaved typing if the app closes unexpectedly.
  • Two-step safety & 100-version history: Boards, cards, and deleted lists' cards are always Archived before permanent deletion, and every content edit records a snapshot with a visual diff viewer.
  • Offline archival PDF/A-2u export: Render any card to a standards-compliant PDF/A-2u document with bundled fonts, clickable links, inline images, and repeating table headers.

Intentional Scope

  • Single-user / personal design: Built for individual workflows — no user accounts, role permissions, or multi-cursor editing. (If you self-host the web version on a server, place it behind a private network or login proxy — see the Technical & Self-Hosting Reference.)
  • Focused data model: One flat Checklist per card, clean simple Tables and Matrices (no merged cells or drag-resized columns), and structured rich text (no raw HTML or script links) keep syncing predictable and PDF exports crisp.

Getting Started

Installing the Desktop App

Install via Homebrew on macOS (Apple Silicon) or download the installer for your operating system from GitHub Releases:

brew install waschmittel/synkban/synkban
PlatformAvailable Packages
macOS (Apple Silicon)Homebrew Cask (waschmittel/synkban/synkban), .dmg installer, and .zip archive
Linux.AppImage and .deb
Windows.exe installer (NSIS)
macOS Gatekeeper note: Installing via Homebrew clears the quarantine flag automatically. If you download the .dmg or .zip manually, macOS may say "Synkban.app is damaged and can't be opened" because release builds are not notarised with a paid Apple Developer certificate. Run this once in Terminal, then open Synkban normally: 
sudo xattr -cr /Applications/Synkban.app
  • Seamless coloured window: The top bar doubles as the window title bar and adapts to the active board's colour and theme.
  • Remembers window geometry: Size, position, and maximised/fullscreen state restore on relaunch and automatically fit onto active monitors.
  • Native integration: External links open in your default browser, and Settings includes a folder picker for choosing your synced Data Directory.
Prefer self-hosting, Docker, mobile PWA, or the standalone web server? Those instructions live separately in the Technical & Self-Hosting Reference so this guide stays focused on daily use.

Two-Minute Walkthrough

  1. Launch Synkban and press N (or click Create new board) to create your first Board.
  2. Press L (or click Add list) to add lists such as To Do, Doing, and Done.
  3. Press N to add a Card using Quick-add tokens directly in the title: Prepare launch notes #work #urgent due:fri and press Enter.
  4. Press Enter on the card to open the Card Modal. Write rich text, add checklist items (Cmd/Ctrl+L), or drag files onto the modal to attach them. Press Cmd/Ctrl+S to save.
  5. Press Cmd/Ctrl+P to export the card to an archival PDF, or close the modal (Esc) and press V to switch into Notes Mode.

Core Concepts

TermWhat it means in Synkban
BoardTop-level workspace with its own title, optional colour, Labels, Lists, and saved view mode (Kanban Mode or Notes Mode).
ListAn ordered group of Cards (side-by-side lane in Kanban Mode, List Tab in Notes Mode) on a board.
CardA work item or note inside a list holding a title, Labels, Due Date, rich-text Description, Checklist, Attachments, and History.
LabelA coloured tag defined per board. Display order is shared across the board, card faces, Card Modal, and Filter Bar.
ArchiveSafe holding area for soft-deleted boards and cards. Items must be archived before they can be permanently deleted.
Data DirectoryThe folder where all boards, cards, and attachments live (boards/). Back up and sync this folder across devices.
Config DirectoryMachine-local folder (~/.config/synkban by default) keeping per-machine Settings and crash recovery. Never synced.

Managing Boards

Board Overview

The home screen (Your Boards) displays all active boards with each board's colour, total active cards, highlighted overdue count, and last edited timestamp (hover for exact local time).

  • Create a board: Click Create new board or press N.
  • Open a board: Click a board card, or move with ↑ ↓ ← → and press Enter.
  • Reorder boards: Drag and drop (long-press on touch), or focus a board and press Shift + arrow keys.
  • Archive / restore boards: Focus a board and press Del / Backspace to archive (confirmed first), or press A to open Archived Boards.

Board Top Bar & Personalisation

  • Inline rename: Click the board title in the centre of the top bar, edit it, and press Enter to save (Esc cancels).
  • Board colour: Click the palette icon for any custom colour with live preview across the background, header, Home tiles, selection highlights, buttons, and focus rings — header text and icons always stay crisp white (very light colours deepen just enough for legibility) and Home tiles adapt ink automatically — or click Reset to default.
  • Quick actions: Back to boards (B), Board / Notes view switch (V), Filter (F), Archived cards (A), Manage labels (G), Keyboard shortcuts (?), and Settings (gear icon).

Switching Boards & Session Memory

When you have two or more boards, a scrollable Board Dock of coloured dots appears at the bottom of the screen. Click any dot, or cycle boards with , / J (previous) and . / K (next).

Switching boards within an open window remembers your last focused card, horizontal and per-list vertical scroll positions, active Filter Bar state, and the last open card per list in Notes Mode.

Kanban Mode & Notes Mode

Every board saves its own view mode (Kanban Mode or Notes Mode) so a board used as a notebook opens in Notes Mode everywhere. Toggle anytime with V or the top-bar switch.

Kanban Mode

  • At-a-glance card badges: Formatted titles, ordered labels, due-date badge, description indicator, checklist progress (done/total), and attachment count.
  • Collapsed Lists: Click a list's collapse chevron or press C while focused inside it to fold it into a narrow vertical strip showing its card count and title. Collapsed lists still accept dropped cards and Shift+←/→ moves (appended to the end), and collapse state syncs across devices.
  • Sticky-row horizontal navigation: Pressing ← / → across lists remembers your vertical row index, so stepping past shorter, empty, or collapsed lists restores your depth on the next taller list.

Notes Mode

Notes Mode turns lists into List Tabs across the top, keeps the active list on the left, and opens the selected card inline on the right in the Notes Pane (centred at a 90-character reading measure; stacks cleanly on narrow windows under 760 px).

  • Navigate: ↑ / ↓ browse cards (switching immediately when clean), ← / → switch tabs, Enter or E jumps straight into editing the description, and Esc returns focus to the selected card.
  • Work with List Tabs: Click the active tab (or press R / F2) to rename the list, click its × to delete it, or drag cards onto any tab (or press Shift+←/→) to move cards between lists.
  • Save & stay: Cmd/Ctrl+S saves without closing and shows "Saved HH:MM". A dot on the card icon and active tab marks unsaved edits; Revert discards them.
  • External conflict protection: If another device syncs edits to the open card while you have unsaved edits in the Notes Pane, Synkban keeps your work and offers a banner to Load theirs or keep yours on Save.

Lists & Cards

Working with Lists

  • Add a list: Press L or click the Add list strip.
  • Rename a list: Click the list header (or active List Tab) or press R / F2.
  • Reorder lists: Drag horizontally, or press Shift+Alt+←/→ while focused on a card or the list's add button.
  • Delete a list: Click × in the header (asks for confirmation if non-empty). All cards inside are moved safely to Archived Cards.

Adding Cards & Quick-Add Syntax

Press N inside a list (or click Add card) and include #label and due:… tokens right in the title — a live preview beneath the field shows what will be applied:

  • #label: Attaches an existing label or creates a new one (dashed border in the preview). Matches loosely ignoring case, spaces, and dashes (#in-progress matches In Progress). Must start with a letter so numbers like #42 stay literal text.
  • due:…: Accepts 2026-12-01, today, tomorrow, weekdays (fri = next Friday), or offsets (+3d, +2w, -1d).

Title Formatting

Card titles and label names support **bold** and *italic* — type markers directly or select text and press Cmd/Ctrl+B / Cmd/Ctrl+I.

Moving & Reordering (Mouse, Keyboard & Touch)

  • Mouse: Drag and drop cards, lists, boards, labels, and checklist items natively.
  • Keyboard: Shift+↑/↓ reorder within a list; Shift+Home/End jump to top/bottom; Shift+←/→ move across lists or tabs; Shift+Alt+←/→ reorder lists.
  • Touch screens: Long-press (~220 ms held still) on any draggable item, drag with edge auto-scrolling, and release. Regular taps and scrolling work normally.

Working Inside a Card

Click a card (or press Enter / Space / E) to open the Card Modal in Kanban Mode or focus the Notes Pane in Notes Mode. Jump straight to any section with Cmd/Ctrl + E (Title), U (Due Date), G (Labels), D (Description), L (Checklist), O (Attachment), J (History), or P (Export PDF).

Deliberate Saves & Unsaved Changes Guard

Title, labels, due date, description, and checklist are edited locally and saved together as one atomic update with Save (Cmd/Ctrl+S). (Attachments save or delete immediately as standalone files.) Leaving a card with unsaved edits prompts Save, Discard, or Cancel.

Rich-Text Description Editor

  • Inline marks & Text Styles: Bold, Italic, Inline code (Cmd/Ctrl+`), Links, Plain text, Code block, Lua block, Heading 1–3, Quotes, and nested Bulleted/Numbered lists (Tab / Shift+Tab or Cmd/Ctrl+]/[ inside lists).
  • Markdown typing shortcuts: Start a line with # , ## , ### , - , 1. , > , ```, or ```lua (press Backspace right after to undo).
  • Smart links: URLs followed by whitespace auto-link; pasting a URL onto selected text wraps it as a link. Plain click opens the link; Cmd/Ctrl+Click edits or removes the whole link cleanly.
  • Editor Menu (Cmd/Ctrl+K or Right-Click): Opens right beside your caret with clickable actions and single-key hints while keeping your selection intact.

Tables & Matrices

Insert a 3×3 Table (Editor Menu T) or Matrix (X) from the toolbar or Cmd/Ctrl+K:

  • Tables: The first row is always the centred Header Row, governing left/centre/right column alignment automatically as rows are added or moved.
  • Matrices: Top-left corner stays empty and uneditable while both the first row and first column act as centred headers, with per-cell alignment on body cells and one-step Transpose (X).
  • Navigation: Tab / Shift+Tab walk cells (Tab at the end appends a row), Enter moves down a row, and Shift+Enter inserts a line break. Inside the Editor Menu: W/S/A/D move rows/columns, Shift+Arrows insert rows/columns, 1/2/3 align, and R/C/T delete.

Lua Blocks (Calculations & Scratchpads)

Embed runnable Lua 5.4 blocks inside any card or note description. Lua blocks are designed specifically for short calculations, quick scratchpads, and inline note helpers — not a full code IDE or external I/O runtime. Because results are saved inside the card itself, exported PDFs, offline reading, and cross-device syncing preserve your output without re-running code automatically.

  • Insert & exit: Type ```lua at the start of a line (converts immediately and consumes an optional Space or Enter), or press Cmd/Ctrl+K then E. Press Shift+Enter to exit into a paragraph below, or Backspace on an empty block to revert to plain text.
  • Highlighting & autocomplete: Native syntax highlighting styles keywords, strings, numbers, comments, and functions. Typing identifiers opens an inline completion popup (locals, globals, and standard libraries); press Tab to accept the top match, use ↑/↓ + Enter to choose an item (Enter alone inserts a newline), or dismiss with Esc without closing the card.
  • Run & persist output: Press Cmd/Ctrl+Enter or click Run to evaluate manually (never runs automatically on open). Saved output shows Ran when current or Outdated after edits; click Clear to remove saved results.
  • Sandboxed execution: Runs offline in a dedicated Lua 5.4 WebAssembly Web Worker with dangerous globals removed (io, package, require, debug), read-only os.time/os.date/os.clock/os.difftime, a 16 MB memory limit, and a 1.5 s timeout.

Inline Images

Embed image attachments straight into a description by pasting an image from the clipboard, pressing Cmd/Ctrl+K then M (or clicking the toolbar image icon), or clicking + on an image attachment tile. Click any inline image for a full-size lightbox preview; copying rich text with inline images to another card copies the image attachments automatically.

Labels & Label Drawer

Press G to open the right-side Label Drawer. Labels auto-assign pastel colours from a 12-colour palette, and you can click any label's colour swatch to pick from the 12 presets or choose any custom colour (card chips, quick-add previews, and exported PDFs automatically switch between dark and white ink for high contrast; Esc closes the colour picker without closing the drawer). Reordering rows here (drag or Shift+↑/↓) controls label display order everywhere on the board. Loose matching prevents duplicates; renaming one label onto another's name triggers a confirmed, board-wide Label Merge. Inside a card (Cmd/Ctrl+G), toggle chips directly or create and assign a new label inline.

Due Dates & Keyboard-First Picker

Click the Due Date chip or press Cmd/Ctrl+U to open the picker. Type 2026-12-01, today, tomorrow, a weekday (fri), or an offset (+3d, +2w, -1d) and press Enter, press ↓ to step through the calendar grid, or click Today, Tomorrow, Next week, or Clear.

Checklist

Press Cmd/Ctrl+L to focus (or expand) a card's flat Checklist. Press Enter to add items rapidly, ↑/↓ to move, Space to check/uncheck, Enter to edit inline, Shift+↑/↓ or drag to reorder, and Del/Backspace to delete (with inline confirmation). Includes a live done/total pill and Check all / Uncheck all toggle.

Attachments

Attach files up to 50 MB each via Cmd/Ctrl+O, dragging files anywhere onto the open card, or pasting images from the clipboard. Image tiles generate thumbnails, open in a lightbox on click/Enter, and display an in text badge when embedded in the description; general files show extension badges and download on click/Enter.

Card History & Diffs

Press Cmd/Ctrl+J to browse up to the last 100 saved content versions of the card (list moves and archiving do not clutter history). Select any version on the left to inspect a field-by-field diff on the right — including row-by-row table diffs, fenced lua blocks with saved output/error lines, and inline image markers.

Archival PDF/A Export

Press Cmd/Ctrl+P (or click the PDF icon) to download a self-contained PDF/A-2u archive of the saved card — complete with embedded fonts, clickable links, formatted headings/lists/quotes/code blocks, Lua blocks with their saved output/errors, inline images, checklists, and tables with repeating headers. If the card has unsaved edits, Synkban asks whether to Save & export or Export saved version.

Filtering Cards

Press F (or click Filter) to open the Filter Bar. All active criteria combine with AND logic: case-insensitive text across titles, descriptions, and checklists; due-date segments (Overdue, This week, or Until… any calendar date); and multiple label chips. Headers and List Tabs show matching/total counts while filtering, and Esc clears active filters before closing the bar.

Archiving & Permanent Deletion

Boards and cards are always Archived first before permanent deletion. Press A on the Board Overview (for archived boards) or inside a board (for archived cards) to Restore items or confirm Delete permanently? Yes / No. Deleting a non-empty list automatically archives its cards safely as Orphaned Cards; restoring one places it back into the board's first list (or active list in Notes Mode).

Syncing, Backups & Crash Safety

Syncing Across Devices

  1. Create a shared sync folder in Syncthing, Dropbox, iCloud Drive, Nextcloud, Git, or rsync.
  2. In the Desktop App, open Settings → Data folder → Browse…, select your synced folder, and click Save & Restart.
  3. If you already had boards in the default folder, copy the boards/ directory into your synced folder manually (changing the folder in Settings does not move existing files automatically).

Sync only your Data Directory — keep your machine's ~/.config/synkban/ folder local. Open boards automatically poll for external file changes every 15 seconds and refresh cleanly without disrupting typing.

Backups & Moving Computers

Copy your Data Directory (or its boards/ folder) anytime — standard file backups (Time Machine, ZIP archives, cloud backup, rsync) work without stopping Synkban. On a new computer, copy the folder over and pick it in Settings → Data folder → Browse….

Crash-Safe Drafts

While a single card has unsaved edits, Synkban keeps a machine-local crash recovery Draft. If the app closes or reloads unexpectedly before you save, the next launch automatically reopens that card with your edits and offers a Discard option (safely dropping the draft if the card changed externally in the meantime).

Warnings & Offline Protection

If Synkban encounters an unreadable or half-synced file, it skips only that file, leaves it intact on disk, keeps the rest of your boards usable, and shows a warning banner naming the exact file path.

Settings & Appearance

Click the Settings gear button in the top-right corner of the header on any page to choose Appearance (System, Light, or Dark with live preview), On startup, open (Board overview or Last used board), and your Data folder.

Keyboard Shortcuts

Press ? anywhere outside text fields (or click the ? button in the top bar) to open the in-app Keyboard shortcuts dialog. It opens directly to the tab matching where your focus currently is (Boards, Board, Notes, Card, or Editor — switch tabs with ← / → or 1–5, and close with ? or Esc).

Troubleshooting & FAQ

macOS says "Synkban.app is damaged and can't be opened"

Release builds are unsigned. Installing via Homebrew (brew install --cask waschmittel/synkban/synkban) clears the quarantine flag automatically. For manual .dmg/.zip installs, run sudo xattr -cr /Applications/Synkban.app in Terminal once and reopen the app.

I changed the Data folder in Settings and my existing boards disappeared

Changing the Data folder points Synkban at the new folder without moving files automatically. Copy your existing boards/ folder from the old Data Directory into the new folder and Synkban will load them automatically.

Why does Synkban have a Save button instead of autosaving every keystroke?

Writing one clean atomic JSON file per save avoids sync churn across Dropbox, Syncthing, and Git and keeps your 100-version Card History meaningful — while machine-local crash drafts still protect every unsaved word if the app quits unexpectedly.

A yellow warning banner says a file could not be read and was skipped — is my data lost?

No. Skipped files remain untouched on disk. Let your sync tool finish transferring (or fix invalid JSON syntax at the path shown) and Synkban picks the file back up on the next refresh.

I accidentally deleted a list — are its cards gone?

No. Deleting a list moves all of its cards into Archived Cards as Orphaned Cards. Press A on the board and click Restore to bring them back.

How can I use Synkban on my phone or tablet?

Self-host Synkban via Docker behind an HTTPS reverse proxy and install it as a Home Screen web app — see the Technical & Self-Hosting Reference.
